#  Personal Portfolio Website

## About

This project is a personal portfolio website designed to showcase my skills, projects, achievements, and professional development as an aspiring Software Engineer. The site serves as a central hub where visitors can learn more about me, explore my work, view my accomplishments, and get in touch.

Built using HTML, CSS, Bootstrap, and GitHub Pages, the website features a responsive design that works across desktop, tablet, and mobile devices. It highlights several software development projects, including web applications, Python programs, and software engineering coursework, while providing an easy way for recruiters, employers, and fellow developers to connect with me.

## Features

- Responsive modern design using Bootstrap 5
- Professional landing page with personal introduction
- About Me section outlining skills and career goals
- Achievement showcase section
- Project portfolio with GitHub repository links
- Contact form powered by Formspree
- Social media integration (GitHub and LinkedIn)
- Mobile-friendly navigation
- Hosted using GitHub Pages

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Formspree
- GitHub Pages

## Purpose

The purpose of this project is to provide an online professional presence while demonstrating front-end web development skills. It also serves as a platform to document my software engineering journey, showcase completed projects, and track my continued growth as a developer.
